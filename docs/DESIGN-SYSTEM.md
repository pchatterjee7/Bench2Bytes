# Bench2Bytes V2 design foundation

Editorial, scientific, and restrained. Georgia serif display headings with Arial body/metadata; system fonts avoid external dependencies. Ink #153044, teal #126b68, paper #faf8f1, muted #51636b, pale panels #eff2ed. Text treatments use dark colors on light backgrounds. Fixed 1180px maximum container, 70ch reading measure, responsive clamp heading sizes, 1000px/650px layout breakpoints. Spacing follows 0.5/1/1.5/2/3/4/5rem intervals.

Shared navigation, footer, metadata, skip link, visible focus ring, one page H1, descriptive section headings. Editorial research rows, ruled publication lists, long-form prose, full scientific figures, governance-spanning lifecycle, and explicit content placeholders. Original images remain intact. Optional image derivatives can be added later without overwriting original assets. No decorative stock imagery, external icons, client framework, or JavaScript animation. Subtle CSS entry/hover transitions provide optional motion. Reduced motion disables smooth scrolling and any future transitions/animations. The portrait uses a crop; scientific figures use contain sizing.

Primary IA: Home, About, AI & Governance, Research, Publications, Leadership, Talks & Writing. Contact is in header/footer. Legacy blog/presentation indexes and project detail routes remain accessible. Research theme links currently lead to the complete inventory, not fabricated filtered results.
